# Generador de Cuenta de Cobro - PEC S.A.S

Aplicación web para generar cuentas de cobro en formato DOCX y PDF
con conversión automática de números a letras.

## Despliegue en Streamlit Cloud

1. Sube este repositorio a GitHub.
2. Ve a https://share.streamlit.io y conecta tu repo.
3. Selecciona `app.py` como archivo principal.
4. Streamlit instalará automáticamente `requirements.txt` y `packages.txt`.
5. ¡Listo!
